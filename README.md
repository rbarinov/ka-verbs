# ka-verbs

Справочник грузинских глаголов из учебников серии **„აღმართი“** (уровни A1, A2, A2+, B1), изданных Министерством образования Грузии для изучающих грузинский как иностранный ([geofl.ge](https://geofl.ge)).

- 1170 глаголов, сгруппированных по уровню, на котором глагол впервые встречается в книгах.
- Для каждого глагола: масдар, настоящее, будущее, аорист, имперфект и оптатив (форма после `მინდა`: `მინდა ვიმუშაო`) во всех шести лицах.
- По три примера с переводом на русский. Примеры с указанием книги взяты из учебников серии, остальные составлены для справочника.
- Поиск по любой форме, по русскому переводу и латиницей в грузинской раскладке (`wer` → `წერ`).

Формы, отмеченные точкой, встречаются в учебниках. Остальные построены по правилам спряжения и проверены, но в редких глаголах возможны неточности.

## Файлы

- `index.html` — весь справочник одной страницей, работает без сервера.
- `data/verbs.json` — те же данные в JSON.

Тексты учебников принадлежат их авторам и издателю; цитаты из них приведены как короткие учебные примеры с указанием источника.
